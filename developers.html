Hi, I'm Zeeshan Malik (listed as Muhammad Zeeshan on the Chrome Web Store). I built Sauvenza after experiencing firsthand how frustrating it is when a browser crash wipes dozens of carefully grouped research tabs—or when legacy tab managers break after Chrome updates, bloat RAM, or lock basic recovery behind mandatory cloud accounts.

Sauvenza is built around three non-negotiable engineering principles: local-first privacy (your browsing history never touches an external server), defense-in-depth reliability (IndexedDB paired with daily rolling storage backups and integrity checks), and a calm, tactile interface that respects your focus.

Engineering Philosophy

  • Zero-Dependency Core: Sauvenza runs on clean, modular ES modules and native Chrome Manifest V3 APIs without bloated third-party frameworks.
  • User-Owned Data Portability: Even if you stop using Sauvenza, your saved sessions remain readable in standard JSON, Markdown, Plain Text, and CSV formats.
  • Respectful Licensing: Pro keys unlock advanced features without forcing subscriptions—offering both an annual plan and a one-time lifetime option.
