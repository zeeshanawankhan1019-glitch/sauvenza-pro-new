Quickstart Manual

How Sauvenza Works Day-to-Day

Everything runs locally inside Chrome Manifest V3 with zero account setup.

1. Recovering After a Browser Crash

  1. Reopen Google Chrome after an unexpected crash, power cut, or forced restart.
  2. Click the Sauvenza icon or press Ctrl+Shift+V (Command+Shift+V on macOS).
  3. Click Restore on the Session preserved banner at the top of the popup to reopen all windows, pinned tabs, and colored Tab Groups.
Privacy Guarantee: Incognito windows are never recorded or persisted in snapshots or rolling backups.

2. Managing Workspaces & Retention

  • Save Current Window: Click Save window in the popup to store all open tabs and groups as a reusable Workspace.
  • Full Vault Dashboard: Click Open vault to inspect auto-snapshots, organize workspaces with calm color tones, and export backups in JSON, Markdown, Plain Text, or CSV.
  • Safe Retention Cleanup: Configure automatic snapshot pruning (7, 30, 60, or 90 days) with a built-in Undo Cleanup buffer so active or pinned workspaces are never lost.
Zero-Friction Switching

Import Sessions from Session Buddy, Toby, or OneTab

Switching from an older Manifest V2 tab manager? Sauvenza includes native parsers that detect your export format automatically and preview every group before importing.

Supported Import Formats

Session Buddy (JSON & Text Exports)

Export your collections or previous sessions from Session Buddy as JSON or formatted text, then drop the file into Vault → Import / Export. Sauvenza reconstructs windows and tab titles cleanly.

Toby (JSON Collections)

Export your Toby lists as JSON. Sauvenza maps each Toby list into an organized workspace or tab group structure with full preview support.

OneTab, Markdown, CSV & URL Lists

Paste exported OneTab link lines, Markdown bulleted link lists, CSV exports, or raw URLs directly into the paste box. Every import supports Merge or Replace (with one-step Undo).

Frequently Asked Questions

Does Sauvenza send my open tabs or browsing history to any server?
No. All open tabs, windows, tab groups, snapshots, and workspaces remain 100% on your device inside Chrome's local IndexedDB and chrome.storage.local. Sauvenza contains zero analytics, zero telemetry, and no cloud account. Network requests happen only when you activate or re-verify an optional Pro license key. Read the full Privacy Policy for technical details.
Why does the Chrome Web Store Privacy tab mention "Web history"?
Chrome Web Store policy requires any extension that uses the chrome.tabs API to read open tab URLs and page titles for session saving to disclose the "Web history" category—even when that data never leaves your local computer. Sauvenza stores all tab data strictly on your device.
What is included in Sauvenza Free vs. Sauvenza Pro?
Sauvenza Free includes automatic crash snapshots (latest 15 snapshots), up to 3 named workspaces, full Chrome Tab Group color and collapse restoration, duplicate tab closing, Markdown copy, and instant keyboard search. Sauvenza Pro ($19/year or $39 one-time lifetime) removes snapshot and workspace limits and adds pinned snapshots, in-place workspace switching, third-party imports (Session Buddy, Toby, OneTab), automatic backup file downloads, custom retention periods, and opt-in Deep Tab Restore.
How does Pro license activation work across browsers?
Each Pro key activates on one browser profile at a time using a randomly generated local browser ID (deviceId). You can click Remove key from this browser in Settings & Pro at any time to release the key and move it to another computer. Offline grace keeps Pro active for up to 30 days if you travel without internet access.
