1. Software Provided "As-Is"

Sauvenza — Crash-Proof Tab & Session Manager ("Sauvenza") is provided on an "as-is" and "as-available" basis without warranties of any kind, whether express or implied, including but not limited to implied warranties of merchantability, fitness for a particular purpose, or uninterrupted browser operation.

While Sauvenza implements automatic background snapshots, daily rolling backups, and integrity checks to minimize the risk of session loss, browser updates, operating system crashes, disk corruption, or manual clearing of browser site data can affect locally stored extension databases.

2. User Responsibility for Off-Browser Backups

Because Sauvenza intentionally stores all tab and workspace data locally on your computer rather than on remote cloud servers, uninstalling the extension or deleting your Chrome user profile will permanently remove your local IndexedDB and storage data.

Users are strongly encouraged to periodically download a portable JSON or Markdown backup file from Vault → Import / Export (or enable automatic backup downloads in Sauvenza Pro) for critical research or production workflows.

3. Opt-In Deep Tab Restore Notice

Sauvenza Pro includes an optional Deep Tab Restore feature that is disabled by default. When explicitly enabled by the user, it captures non-sensitive text inputs in standard HTTP/HTTPS web pages locally so drafts can be restored after a crash. Although Sauvenza filters out password, hidden, file, payment/CVV, token, and autocomplete="off" fields, users should avoid relying on browser form caching as a substitute for saving critical documents in their native web applications.
